Cascade

Two identical buttons, one shared token: --color-cake-primary. Their hover, active, disabled and focus-visible states are auto-generated with color-mix() — zero manual hex codes. Colors move at 0.15s ease-out, transforms at 0.3s cubic-bezier(0.2, 0.8, 0.2, 1) — snappy and mechanical. The Override Protocol classes in the Buttons section break the rules locally without ever touching a global variable.

Type is set in Inter, loaded from Google Fonts (400 text · 500 buttons · 600 headings). Offline, the --font-sans token falls back to system-ui — the demo still works from file://.
